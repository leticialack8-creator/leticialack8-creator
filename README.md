## 🚀 Projetos em destaque

### 🐾 DoctorPet

Plataforma web acadêmica para encontrar veterinários que atendem cães e gatos.

O projeto foi desenvolvido para simular uma plataforma de busca de profissionais veterinários e agendamento de consultas.

**Funcionalidades:**

- Pesquisa de veterinários por cidade e especialidade
- Filtros para atendimento de gatos e cachorros
- Seleção de atendimento presencial ou teleconsulta
- Visualização de perfis de veterinários fictícios
- Horários demonstrativos específicos por profissional
- Simulação de agendamento com nome do pet, data e horário
- Interface responsiva

**Tecnologias utilizadas:** HTML5, CSS3 e JavaScript.

🌐 [Visualizar o DoctorPet funcionando](https://leticialack8-creator.github.io/DoctorPet/)

### 🎬 CineBenefícios

Projeto acadêmico de uma aplicação web para apresentação de filmes e cupons promocionais demonstrativos.

O objetivo é proporcionar uma experiência interativa de navegação, pesquisa e visualização de informações sobre filmes.

**Funcionalidades:**

- Pesquisa de filmes por nome
- Visualização e ocultação de detalhes
- Navegação entre seções da página
- Cópia de cupons promocionais fictícios
- Interface responsiva

**Tecnologias utilizadas:** HTML5, CSS3 e JavaScript.
